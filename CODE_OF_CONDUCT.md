# Code of Conduct

## Our standard

Project spaces should be safe, professional, and useful. Be respectful,
assume good intent while checking evidence, accept correction, and focus
criticism on technical work rather than people.

Unacceptable behavior includes harassment, discrimination, threats, sustained
disruption, publishing another person's private information, or exposing
credentials and customer data.

## Enforcement

Report conduct concerns privately through the repository maintainer contact
shown in the GitHub Security or project profile. Maintainers may edit or remove
content, issue a warning, temporarily restrict participation, or permanently
remove a participant based on severity and pattern.

Maintainers will protect reporter privacy as far as practical and will disclose
conflicts of interest. This policy applies to repository discussions, reviews,
issues, release channels, and project events.
